# Dynamic Economy

This folder contains the concept notes for a dynamic economy idea. The working goal is to create a living economic loop in which resources, values, and scarcity shift with player behavior and local conditions.

## Current status

- Concept and design notes are in progress.
- This folder acts as the entry point for the idea while the broader economic system is still being explored.

## Themes

- Resource scarcity and regional variation
- Supply chains and demand shifts
- Player-driven market disruption
- NPC or world response to economic pressure

## Recommended next steps

1. Identify the core resource loop.
2. Define what drives prices up or down.
3. Decide how world events alter local economies.
4. Test whether the system reads clearly to players without excessive UI complexity.
