# Sell Barrel Resources v1.0.3

This resource pack supplies uniquely named Sell Barrel textures and its display name without overriding the vanilla barrel textures. The behavior pack declares this pack as a dependency so Minecraft can resolve the block textures and name. The **Upcoming Creator Features** experiment must be enabled for the Sell Barrel's custom block inventory. Enable this resource pack alongside Dynamic Economy v0.3.13 under Behavior Packs. The Sell Barrel side, top, and bottom images are based on the vanilla Bedrock barrel textures with the RGB channels inverted and alpha preserved; the pack also assigns the custom block the vanilla wood sound group.
