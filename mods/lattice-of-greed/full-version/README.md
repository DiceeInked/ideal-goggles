# Lattice of Greed 1.5.0: Three Void Realms

This release fixes three important problems in the previous pack: saved terrain was being regenerated by a forced recheck, container loot was not reliably populated, and rooms lacked architectural variety.

## What's changed

- **Saved regions stay saved.** Rechecks no longer bypass the persistence marker. Once a region finishes generating, routine chunk visits and `/function lattice_recheck` do not reconstruct its terrain or restore blocks players have mined.
- **Separate terrain and loot persistence.** Each region records its terrain completion and its container-loot completion separately. If a chest or barrel cannot be accessed during the first fill attempt, the next attempt fills containers only and does not rebuild the room.
- **Real inventory contents.** Generated chests and barrels are filled using the Bedrock Script API inventory component and `ItemStack`. The starter chest guarantees basic survival supplies; other containers mix common resources, biome-themed items, structure-themed loot, and occasional rare finds.
- **Rooms have different floorplans.** Nine seeded layouts create colonnades, split halls, archives, central dais rooms, bent corridors, broken halls, vault rings, reliquaries, and workshops. Room dimensions, accents, container positions, and loot rolls vary by region.
- **Structure clusters are rarer.** Large themed clusters appear only once per 3×3 region tile. The lattice and small resource islets continue between them, making the map feel larger and leaving more open space to explore.
- **Legacy container migration.** Regions saved by version 1.3.1 can receive loot in their existing chest/barrel positions once. A container that already contains items is left alone.

The pack still includes 56 biome-themed profiles and 21 structure-room themes. These are compact, handcrafted structures inside the custom lattice dimension, not complete vanilla structures.

## Install safely

1. Back up your world before replacing a behavior pack.
2. Import `Lattice-of-Greed-Full-1.5.0.mcpack`.
3. Deactivate the older Lattice of Greed behavior pack for the test world, then activate version 1.4.0.
4. Enter the custom dimension and let nearby generation finish before exploring quickly.
5. Check a new room's chest and barrels. The first migration can fill existing empty containers in regions generated by 1.3.1.

**Important:** the new version cannot undo changes already made to your world, and an existing room won't be rebuilt just to gain the new floorplan. New layouts appear in newly generated regions. This is intentional so players' builds and mined blocks are preserved.

## Commands

- `/function function_check` confirms the function file is loaded.
- `/function lattice_status` shows generation status and the last generation error.
- `/function lattice_recheck` checks nearby regions. It does not regenerate saved terrain; it can only retry unfinished generation or missing one-time loot population.

The automated workflow checks syntax, catalogue counts, persistence guards, sparse cluster rules, and the importable package. Those checks cannot substitute for a live Bedrock playtest. I have not tested this pack inside your actual world, so please try it in a backup or test world before using it with friends.


## Version 1.5.0: Void Nether and End

- Registers two additional void custom dimensions: `log:nether_void` and `log:end_void`.
- Entering a vanilla Nether or End portal routes the player into the corresponding custom void realm. The built-in vanilla dimension may still exist internally, but its terrain is not shown to the player after the script redirects them.
- The Nether realm has horizontal lattice beams only, with no vertical beams, plus sparse netherrack, basalt, blackstone, crimson, warped, soul-soil, and fortress-inspired regions.
- The End realm uses isolated intersection dots instead of lattice beams, with sparse End islands and rare purpur towers.
- A rare scripted End gate is placed at X=256, Z=256 when explored nearby. Using an Eye of Ender still performs its vanilla action and also displays the custom gate coordinates. Enter the gate's center to travel to the custom End.
- Return gates in the custom realms take players back to the Overworld.

**Compatibility note:** Bedrock's documented custom-dimension API creates void dimensions; it does not replace the built-in Nether/End terrain generator. This pack redirects players after they enter the vanilla dimensions, so the built-in terrain is not used for exploration. The custom End realm is not the vanilla End, so the vanilla Ender Dragon fight, outer-island generation, and vanilla End-city generation are not included automatically.
**Playtest note:** Static validation checks syntax and package contents. Test portals and block generation in a backed-up world before using it as a main save.
