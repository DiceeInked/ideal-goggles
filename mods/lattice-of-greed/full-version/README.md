# Lattice of Greed: Spreading Islands 1.2.0

This release keeps the bedrock lattice and original starter oak tree, then adds spreading plant islands and three types of cave-resource island systems.

## What's in the world

- **Bedrock lattice:** beams every four blocks from Y=-32 through Y=0.
- **Starter tree island:** a 3×3 dirt-and-grass island with an oak tree and a bedrock core. Spawn now lands safely beside the trunk on this island.
- **Vegetation islands:** other 3×3 dirt islands with grass on top. Each gets one to three flowers, grasses, occasional oak saplings, or sweet-berry bushes. They are more likely near the starter tree and become less frequent farther away.
- **Lush cave systems:** moss, rooted dirt, clay, grass, plants and berries, with coal, iron and copper among the main-island resources.
- **Dripstone cave systems:** stone, tuff and dripstone, with coal, iron and copper on the main island.
- **Amethyst cave systems:** calcite, smooth basalt and amethyst blocks, with iron and copper on the main island.

## Cave island layout

Each cave system has **one main island plus twelve smaller surrounding islands**. The main island has several useful resource blocks. Each surrounding island has less: usually a themed cave block, with roughly one in four satellite islands receiving an extra ore block.

The systems repeat in 6×6 lattice-cell areas, which are roughly 24×24 blocks. Their cave type is selected deterministically from lush, dripstone or amethyst, so the same world coordinates keep the same layout when you return.

## Spreading vegetation

Plant islands are chosen independently for each lattice cell, except where a cave island already occupies that cell. The chance is approximately:

- **45%** within 3 lattice cells of the starter tree
- **30%** within 4–8 cells
- **16%** within 9–20 cells
- **5%** farther away

That makes the tree's plant islands a little archipelago rather than a solid forest. These percentages determine island placement, not the success rate of natural plant growth.

## Automatic generation and survival persistence

The script queues your current region first, then nearby regions outward every half second. It uses a configurable radius of **4 chunks in each direction** (up to a 9×9 square). The Bedrock Script API does not expose a player's exact render-distance setting, so this remains an approximation.

After a region's structures finish generating, the pack saves a world marker for that region. That keeps mined resource islands from being recreated after a restart or when players return. The bedrock lattice can still be rebuilt by the generation system.

## Install

1. Deactivate older Lattice of Greed behavior packs in the world's settings.
2. Import the file named Lattice-of-Greed-Full-1.2.0.mcpack.
3. A new world is recommended for the cleanest survival start.
4. Activate the behavior pack and join the world.
5. Stay near the starter island briefly while the surrounding regions generate.

An older 1.1.0 world may also receive new islands as its regions are first generated by 1.2.0. Because that older version did not save structure markers, the original starter tree area can be generated again during the upgrade. Back up the world first if you have builds you care about.

## Diagnostics

- /function function_check confirms Minecraft loaded the function file.
- /function lattice_status reports the current region, number of regions built, queued work and scan radius.
- /function lattice_recheck rebuilds the current lattice region and queues nearby regions. It does not intentionally reset islands in regions whose structures have already been marked as generated.

Each placement is checked before the script advances. The repository's automated checks validate JavaScript syntax and the package structure; **only an in-game test can confirm the behavior in your particular Minecraft world and device**.
