# Lattice of Greed

This folder holds the concept and build history for the Lattice of Greed idea. It contains multiple versioned packs and supporting notes, so this README acts as the reference entry point.

## Overview

The concept centers on a repeating territory or resource lattice that rewards exploration, claims, control, and strategic expansion. It sits in the same family of ideas as the broader lattice experiments in this repo, but it has its own full-version track and build history.

## Contents

- `Initialconcept.md` — early idea notes
- `full-version/` — packaged and versioned releases
- `prototype/` — earlier prototype work

## Best path for browsing

- Start with `Initialconcept.md` for the original concept.
- Use the `full-version` folder for packaged builds and release history.
- Use the `prototype` folder for earlier experimentation or comparison.

## Notes

This project is broader than a single script or behavior pack; it includes both design and implementation history. The package layout is intentionally versioned so older builds remain easy to compare.
