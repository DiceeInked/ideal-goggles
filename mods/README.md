# Mods

This folder contains the Minecraft Bedrock add-on experiments and concept packs for the project. Each subfolder is an idea or prototype, and the structure is intentionally simple so the repo remains easy to browse.

> Legacy note: some older mod folders use older naming patterns from earlier drafts. This index is the canonical overview, while the original folders remain available for history and continuity.

## Active ideas and prototypes

- [ExplorationLattice](ExplorationLattice/README.md) — terrain-lattice behavior pack with chunk-scanning and progressive terrain removal.
- [dynamic-economy](dynamic-economy/README.md) — concept exploration for a dynamic economy system.
- [lattice-of-greed](lattice-of-greed/README.md) — larger full-version concept build for the lattice economy/territory idea.
- [no-command-limits](no-command-limits/README.md) — experiment or command-limit concept.
- [resin-lattice](resin-lattice/README.md) — variant concept related to the broader lattice design set.
- [spam-start](spam-start/README.md) — early prototype or testing pack.
- [trappedindeath](trappedindeath/README.md) — concept note or prototype for a death/trap-focused idea.

## Suggested usage

- Use the README in each folder for the idea summary and version notes.
- Use versioned `.mcpack` files when testing builds in Minecraft.
- Keep concept files such as `Initialconcept.md` or similar notes in the same folder for that idea.

## Naming convention for future additions

Use lowercase, hyphenated folder names for new mod entries whenever possible, such as:

- `exploration-lattice`
- `dynamic-economy`
- `lattice-of-greed`

This keeps the directory list easier to scan and more consistent with the rest of the repo.
