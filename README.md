# ideal-goggles

Minecraft Bedrock add-on projects tracked as source and versioned releases.

- Dynamic Economy and Sell Barrel: `mods/dynamic-economy/bedrock/`
- Sell Barrel resource pack: `mods/dynamic-economy/resource-pack/`
- Recovery Compass: `mods/recovery-compass/bedrock/`

Dynamic Economy's pack UUID and market/balance property names stay stable across compatible updates. Back up a world before changing add-ons.
