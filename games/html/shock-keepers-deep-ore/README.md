# Shock Keepers: Deep Ore

This is a small HTML browser prototype built for the ideal-goggles repo.

What it includes:
- cave exploration with a player character
- mining glowing ore veins
- a weapon build system using blade, handle, and amulet parts
- enemy shock keepers that patrol the mine and deal damage
- a basic upgrade loop with shards, ink, and deeper cave levels

Controls:
- WASD or arrow keys: move
- Space or hold left click: mine ore
- E: shock burst ability

Open `index.html` in a browser to play.

This is a lightweight prototype inspired by the repo’s Drawing Adventure Game notes, especially the mining, weapon-part structure, and underground shock-keeper feel.
