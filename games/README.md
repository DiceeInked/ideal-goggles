# Games

This folder contains smaller browser-based or lightweight game experiments that do not belong in the larger design-document sections.

## Current contents

- [html/crowded](html/crowded/index.html) — a small HTML experiment or prototype.
- [html/shock-keepers-deep-ore](html/shock-keepers-deep-ore/index.html) — a mining action prototype with weapon parts and shock keepers.

## Notes

- Keep one-off experiments in this folder rather than mixing them into the main design folders.
- If a prototype turns into a larger concept, move the documentation to the relevant project section and keep the prototype as a historical artifact.
